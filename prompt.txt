FubaMaps - Audit Final, Cohérence Métier et Migration GeoDjango/PostGIS

OBJECTIF

Analyser l'intégralité du dépôt FubaMaps puis effectuer toutes les corrections nécessaires afin d'obtenir :

- une architecture cohérente ;
- une géolocalisation professionnelle basée sur GeoDjango et PostGIS ;
- une cohérence métier stricte entre Catégories, Types et Commerces ;
- une validation robuste des données côté Backend et Frontend ;
- une base prête pour la montée en charge.

- django.contrib.gis

Commerce.category == Commerce.type.category
